# 벽돌 철거반

쇠공을 튕겨 벽을 허무는 벽돌깨기 웹 게임이에요. 레벨마다 실제 벽돌 쌓기 방식(길이쌓기, 영국식 쌓기, 플레밍식 쌓기, 마구리쌓기, 창문 벽)으로 지은 벽이 나와요.

**플레이:** https://seungbeom-code.github.io/brick-breaker/

## 안드로이드 폰에 설치하기

1. 크롬에서 위 주소를 열어요.
2. 오른쪽 위 ⋮ 메뉴에서 **홈 화면에 추가**(또는 **앱 설치**)를 눌러요.
3. 홈 화면 아이콘으로 열면 전체 화면으로 실행돼요. 한 번 열어 둔 뒤에는 인터넷 없이도 열려요.

## 조작

- 폰: 화면을 누른 채 좌우로 밀면 패들이 움직이고, 손을 떼면 공이 나가요.
- PC: 마우스나 ← → 키로 이동하고, 클릭이나 스페이스로 발사해요. P 또는 Esc로 일시정지해요.

## 레벨이 오르면

- 공은 레벨마다 조금씩 계속 빨라져요.
- **4레벨마다** 새로운 돌이 하나씩 나와요. 돌마다 성질이 달라요. 게임 안의 **돌 도감**에서 볼 수 있어요.
- **10레벨마다** 난이도가 한 단계 올라요(패들이 짧아지고 단단한 벽돌이 늘어요). 대신 공을 하나 선물로 받아요.

| 레벨 | 돌 | 성질 |
|---|---|---|
| 4 | 사암 | 공이 뚫고 지나가요 |
| 8 | 화강암 | 네 번 맞혀야 깨져요 |
| 12 | 흑요석 | 맞으면 공이 한동안 빨라져요 |
| 16 | 발파석 | 깨지면 터져서 둘레 벽돌도 부숴요 |
| 20 | 자철석 | 가까이 지나가는 공을 끌어당겨요 |
| 24 | 옥 | 깨면 패들이 한동안 길어져요 |
| 28 | 대리석 | 공이 엉뚱한 쪽으로 튀어요 |
| 32 | 수정 | 깨면 공을 하나 더 얻어요 |
| 36 | 호박 | 맞으면 공이 한동안 느려져요 |
| 40 | 금광석 | 깨면 한동안 점수가 두 배예요 |
| 44 | 운석 | 여섯 번 맞혀야 깨지고 점수가 커요 |
| 48 | 금강석 | 여덟 번 맞혀야 깨져요 |

벽 모양은 13가지예요. 기본 쌓기 다섯 가지에 박공벽, 영롱쌓기, 성가퀴, 아치문, 계단벽, 마름모 벽, 쌍둥이 탑, 줄기둥이 번갈아 나와요.

## 데모 화면

시작 화면을 8초쯤 그대로 두면 게임이 혼자 돌아가는 데모가 나와요. 데모 중에는 화면 가운데에 순위표 5위까지가 계속 보여요. 화면을 누르면 시작 화면으로 돌아가요.

## 순위표

게임이 끝나면 영문 이름을 적어 점수를 순위표에 올릴 수 있어요. 기록은 Firebase Firestore에 저장돼요.

- 저장하는 것은 이름, 점수, 도달 레벨뿐이에요.
- 서버가 받는 형식은 `firestore.rules`에 적혀 있어요. 이 파일을 고치면 Firebase 콘솔의 **Firestore Database → 규칙**에도 같은 내용을 붙여 넣고 게시해야 해요.
- `index.html`의 `BOARD.project`가 Firebase 프로젝트 ID예요. 비어 있으면 순위표 기능이 꺼져요.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 게임 전체 (HTML·CSS·JavaScript 한 파일, 외부 라이브러리 없음) |
| `manifest.webmanifest`, `icon-192.png`, `icon-512.png` | 홈 화면 설치용 앱 정보와 아이콘 |
| `sw.js` | 오프라인 실행용 서비스 워커 |
| `firestore.rules` | 순위표 서버(Firestore)의 보안 규칙 |
| `.nojekyll` | GitHub Pages가 파일을 그대로 올리도록 하는 표시 |
